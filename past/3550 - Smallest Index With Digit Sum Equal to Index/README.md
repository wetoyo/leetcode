# Smallest Index With Digit Sum Equal to Index

[LeetCode #3550](https://leetcode.com/problems/smallest-index-with-digit-sum-equal-to-index/) — Difficulty: Easy

## Problem
find the first index where the digit sum is equal to the index

## Approach
loop through and compute the digit sum

## Complexity
- Time: O(n)
- Space: O(1)
