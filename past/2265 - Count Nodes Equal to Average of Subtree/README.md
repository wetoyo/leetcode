# Count Nodes Equal to Average of Subtree

[LeetCode #2265](https://leetcode.com/problems/count-nodes-equal-to-average-of-subtree/) — Difficulty: Medium

## Problem
binary tree, find if the avg val of the subtree is the samea s the val of the root. count how many times this happens in the tree

## Approach
recursive approach for the sum, then did some fiddling to get the size of the subtree propagated upward.

## Complexity
- Time: O(N)
- Space: O(N)
