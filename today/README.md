# Unique 3-Digit Even Numbers

[LeetCode #3483](https://leetcode.com/problems/unique-3-digit-even-numbers/) — Difficulty: Easy

## Problem
Given an array of numbers (not unique) find how many permutations of size 3 exist that are even.

## Approach
Recursivly count all options since n is limited to 10

## Complexity
- Time: $O(n^3)$
- Space: $O(n^3)$

### Notes
- not sure about the time complexity, but I believe that the three digit cap makes it $n^3$ rather than $n!$
